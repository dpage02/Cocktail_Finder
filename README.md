# The Cocktail Finder

The bar's working cocktail archive: browse by family, spirit or flavor, check what you can make
with what's on the shelf, and plan seasonal menus.

**Live site:** https://dpage02.github.io/Cocktail_Finder/

- `index.html`: the whole site
- `seed.json`: saved data carried over from the original Claude version
- `apps-script/Code.gs`: the Google Sheet backend that stores crew changes
- `SETUP.md`: one-time setup steps
